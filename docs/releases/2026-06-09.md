# Release notes — 2026-06-09

Thirteen PRs (#4–#16) landed today: the public **aether-agent** rebrand plus a
large slash-command expansion that turns the REPL into a full agent console.
Every new slash command is documented in [COMMANDS.md](../COMMANDS.md).

## Highlights

- **Rebrand to Aether Agent** — embeddable terminal renderer + public name change land on `main`.
- **Slash-command console** — Session, Agent-mode, Steering, Context, Goals, Vault, and Orchestra command groups.
- **QOPC memory bridge** — live behavioral-memory display in the terminal.
- **Workflows + Goals** — save/export/import workflows and persistent goal chains with phase boxes.
