# Aether Agent v0.3.2 — one line again

This patch reunites the v0.3.1 maintenance line with `main`. v0.3.1 was released
from a branch that was never merged, so `main` carried on without its
browser-launcher verification and browser-login recovery, while still declaring
`0.3.0` — a version behind the one the registry was serving. The merge lands
those fixes and takes the next patch number, so the source tree leads the
published version again.

It adds no command, flag, or contract of its own. The device-runtime, telemetry,
and session-library work already on `main` is carried by the merge and is not
announced as new here.

Packet: [OPERATOR-PACKET-v0.3.2.md](OPERATOR-PACKET-v0.3.2.md).

## Also on 2026-09-03 — public documentation

**The README was rebuilt around the first run.** The page opens on a recording
of install → launch → `/help` → `/models`, then answers the three questions a
newcomer actually has — how do I install it, where does the model run, and what
stays on my machine — before it reaches reference material. The product boundary
did not move: hosted coding stays account-dependent, the local route still needs
no account, and the CLI still makes no cross-surface continuation claim.

**Aether Code and `/rc` are named for the first time.** The web surface is linked
as a sibling product rather than a continuation of the CLI, and the `/rc`
remote-viewing lane is described as what it is — an in-progress host, not part of
0.3.x — with its outbound-only, viewer-only, redacted invariants written down
where users can hold us to them.

**A follow-up pass tightened it.** The demo now opens on the finished startup
banner rather than an empty prompt, so its still frame carries the product, the feature list dropped the three bullets that
restated other sections, the model catalogue was separated from the
hosted-versus-local choice it was being confused with, and the boundary list
was rewritten to be scannable.

No runtime, package, entitlement, or release behaviour changed.
