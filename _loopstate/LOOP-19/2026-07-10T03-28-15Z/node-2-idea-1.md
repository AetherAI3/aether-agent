## Problem framing

aether-code's individual surfaces are well-built, but the seams between them lie in small ways: the splash advertises a slash command that does not exist (splash.ts:25 `/effort` — no case in slash.ts, and envelope.ts has no effort field to wire it to), main.ts:21 hardcodes a second VERSION next to the declared single source, a default `aether code` run ends `unverified` with no hint that `--test-cmd` exists, a typo like `aether auht` silently becomes a paid cloud chat call, and success/failure vocabulary drifts per file (`✓ Logged in.` vs `✓ logged in (…)` vs bare `refresh failed`; cyan `[ OKAY ]` vs unstyled `[ FAIL ]`). None of this needs new machinery — it needs the existing machinery to stop contradicting itself.

## Approach

12 independent micro-commits against existing files only: honesty fixes (stop advertising ghosts, hint at the verify gate, catch typos before they cost API calls), consistency fixes (one kaomoji source, one ✓/✗ vocabulary, theme everywhere theme already goes), one graceful-exit courtesy. All styling through existing theme wrappers (C2 by construction).
