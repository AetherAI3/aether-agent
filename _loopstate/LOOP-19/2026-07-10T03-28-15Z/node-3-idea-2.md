# LOOP-19 · Node 3 — IDEA-2 (forced angle: most ambitious / highest ceiling)

Generated by an independent advocate agent, blind to ideas 1 and 3.

## Problem framing

aether-code has the *organs* of a first-class agent terminal but no *body*. The best UI component in the repo — `TuiLayout` (src/ui/tui_layout.ts), a complete alt-screen pager with header/transcript/status/input regions, follow-at-bottom scrolling, an "N new" hint, resize handling, and a tested non-TTY degrade — is imported by exactly one file: its test. Meanwhile the actual REPL (chat.ts:70-106) is a bare `createInterface({ input })` with no output: no input history, no arrow keys, no live status during a turn, no way to scroll a long answer, no multi-line prompts. During a streaming turn the only liveness signal is `\r⟢ N UVT` overwrites on stderr. `aether code` has a genuinely good live surface — but chat and code share *nothing* above the theme. The gap to Claude Code / codex-cli is not one feature; it is the absence of a coherent live application. The interfaces already line up: TuiLayout has `log/setHeartbeat/setStage/setUvt`, which is exactly the sink shape `bindEventSource` drives (agent_events.ts:136-150).

## Approach

One live terminal application with two render surfaces behind a single `Surface` interface: full-screen `TuiSurface` (TuiLayout, persistent REPL) and inline `InlineSurface` (StatusRenderer semantics, run-to-completion `aether code`). Day one: `aether` in a TTY opens an alt-screen app — cloud splash pinned as header, scrollable transcript (PgUp/PgDn/End, "paused · N new"), live status row pulsing the heartbeat on SSE arrivals and filling the UVT bar, pinned `[user]_: ` input with real editing (arrows, Home/End, persistent history, Ctrl+J multi-line). Slash commands print into the transcript; `/resume` lists prior sessions from ~/.aether-code/logs and pages them back. `aether code` keeps inline by default, gains `--tui`. All non-TTY/--json/NO_COLOR/NO_ANIM paths fall back to today's exact plain output.

## Key risks

- **Character width math (highest)**: kaomoji/CJK/combining chars break 1-cell assumptions; no wcwidth dep allowed → heuristic + confine kaomoji to row-ends + accept documented imperfection.
- **Raw mode signal semantics**: setRawMode suppresses SIGINT; every driver error path must funnel through one terminal-restore or users get stranded on alt-screen.
- **Windows terminals**: legacy conhost is shaky (SGR mouse, shift-arrow variants, resize). Mouse off by default; AETHER_NO_TUI escape hatch; test Windows-first.
- **Alt-screen loses native scrollback/copy**: print last N transcript lines to main screen on exit; mouse capture off preserves selection.
- **Readline coexistence**: any createInterface while raw mode active fights the key loop (interact.ts:33, login.ts:127) — all prompts must route through the surface's PromptIO.
- **Streaming tail × wrapping**: repaint only tail's physical rows; batch deltas per ~33ms frame.
