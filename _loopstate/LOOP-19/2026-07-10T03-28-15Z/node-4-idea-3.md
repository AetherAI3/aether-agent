# LOOP-19 · Node 4 — IDEA-3 (forced angle: cheapest / fastest, max felt value ≤ 1 day)

Generated by an independent advocate agent, blind to ideas 1 and 2.

## Problem framing

A first-time user's 10 minutes with `aether` today: they type a prompt, press Enter, and stare at a **silent terminal** until the first SSE frame lands (not one byte written between submit and first frame). They press **up-arrow** and get `^[[A` garbage (readline constructed with input only, chat.ts:71). They typo `/modle` → flat `unknown command`. A network hiccup → `✗ fetch failed` with no clue whether they're logged out or offline. A reflexive **Ctrl+C** on a rambling answer kills the entire session (no SIGINT handling; no AbortSignal in transport.ts:51-76). "Thinking" text is raw undimmed stderr, visually identical to the answer. `aether code` ends a 5-minute run with just `⤷ log: <dir> · incomplete` — it *computes* the failing-test count (code.ts:216-217) and shows it only to the log file, never the human.

## Approach

Fix only what a user physically feels in minute one: input recall/completion, time-to-first-feedback, cancel-without-dying, and error/summary lines that say what to do next. Thin layers at existing seams, each committable alone, pure unit-testable helpers, zero deps, zero protocol changes.

## Concrete changes (≤7, with hours)

1. **Real readline: persisted up-arrow history + slash tab-completion + owned prompt** (chat.ts:71-101 + slash.ts). Full construction: `{ input, output, prompt, terminal: isTTY, historySize: 200, history: loadHistory(), completer }`; replace 4 manual prompt writes with rl.prompt(); history at `join(configDir(), "history")` (AETHER_CONFIG_DIR honored); export SLASH_COMMANDS + pure `slashCompleter`. Non-TTY bytes unchanged. **2.5h.** Tests: completer cases + history round-trip.
2. **Thinking pulse — kill dead air** (new src/ui/thinking.ts ~40 lines + runTurn). `\r(⌨_⌨) thinking···` cycling dots ~120ms on stderr; start before stream, stop on first frame + finally. Gate mirrors status_renderer: `stderr.isTTY && !json && AETHER_NO_ANIM!=="1"`; disabled = zero bytes. Benefits REPL, one-shot, and `run.ts` (all route through runTurn). **1.5h.** Tests: pure composer + disabled-writes-nothing.
3. **Ctrl+C cancels the turn, not the session** (transport.ts stream() gains `signal?: AbortSignal` → fetch; runTurn threads it; REPL per-turn AbortController; rl SIGINT + process.once fallback; mid-turn → abort + dim `✗ canceled` + reprompt; idle → clean exit). Pure `isAbortError` (name + cause). **2h.** Tests: isAbortError + stubbed fetch asserting signal.
4. **Actionable error hints** (errors.ts + printError + main.ts catch). Pure `errorHint(err, baseUrl)`: 401/403 → `run: aether auth login`; 429 → `rate/UVT limit — see /tier`; fetch-failed/ECONNREFUSED/ENOTFOUND/ETIMEDOUT → `can't reach <baseUrl> — offline? try /doctor`. Second dim line under ✗. **1h.** Tests: pure hint cases. (A sibling loop artifact in dist/ independently converged on this — evidence of value.)
5. **Did-you-mean for slash typos** (slash.ts default case). Pure `suggestSlash` (prefix, else Levenshtein ≤2, ~15-line DP). `unknown command: /modle — did you mean /model?  (/help lists commands)`. **1h.** Tests: suggestion cases.
6. **One-line end-of-run summary for `aether code`** (code.ts + pure `runSummary` in code_support.ts). Track write_file paths + start time; after verify gate print `✓ ok · 4 files changed · tests green · 3m12s` / `✗ incomplete · 2 tests failing · …`. Surfaces the computed-but-hidden `remaining`; prints even with --no-log (which today ends with NOTHING); skipped under --json. **1h.** Tests: pure runSummary cases.
7. **Dim the reasoning stream** (render.ts:70 → `theme.dim(f.text)`). One line; identity under non-TTY; --json returns earlier. **0.5h.**

## Key risks

- Change 1 is the only genuinely behavioral one: terminal-mode readline echo/repaint quirks across conhost vs pty. Mitigate: `terminal: process.stdout.isTTY`, keep for-await loop shape, manual smoke both modes.
- Abort classification: undici may surface AbortError vs wrapped cause; isAbortError checks both; one manual live test.
- Changes 1↔3 interact (SIGINT arrives via rl only when terminal:true) — hook both rl + process paths so either commit order stays green.
- theme.enabled snapshots stdout.isTTY and is applied to stderr (pre-existing quirk, inherited, not fixed).
